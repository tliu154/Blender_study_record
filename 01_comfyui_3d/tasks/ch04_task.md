# 实操 04：导出不同格式并验证

> 对应章节：[第 4 章 3D 模型格式与导出](../docs/ch04_formats.md) ｜ 预计耗时：40 分钟
> 状态：`[已完成]`

## 目标

把 ch02/ch03 生成的模型导出成不同格式，验证贴图是否跟随，理解"按用途选格式"。

## 前提

- [ ] 有一个已生成的 3D 模型（ch02 或 ch03 的结果，带或不带贴图都行）
- [ ] 一个能打开 glb/obj 的查看器（Blender / 在线 glTF 查看器 / 系统 3D 查看器）

## 步骤

1. **导出 glb**：从 ComfyUI 的导出节点（或先导入 Blender 再导）导出一份 `.glb`，
   选内嵌贴图选项（若有）。记录文件大小。

2. **验证 glb**：在查看器打开，确认能看到模型 + 贴图。
   - 贴图在吗？____ ｜ 文件大小 ____ MB

3. **导出 obj（可选）**：导出一份 `.obj`，看是否同时生成 `.mtl` 和贴图图片文件。
   把这三个（类）文件**一起**挪到一个新文件夹，再用查看器打开，验证贴图还在。
   - 生成了哪些文件：____________

4. **按用途选格式决策**：假设三个场景，各写出你会导出的格式+理由：
   - 发给朋友在网页上看：____（理由：____）
   - 送 3D 打印：____（理由：____）
   - 导入游戏引擎：____（理由：____）

5. **找坑**：故意在导出时改一个设置（如 Up 轴、或只拷 obj 不拷贴图），
   观察下游出现什么问题，对照 [ch04 4.4](../docs/ch04_formats.md#c04-04)。

## 验收标准

- [ ] 成功导出 glb 并验证贴图
- [ ] 能说出 glb vs obj 在贴图携带上的区别
- [ ] 三个场景的格式选择都填对
- [ ] 至少观察到一种导出坑的现象

## 改一改会怎样（小实验）

| 改动 | 预期现象 | 为什么 |
|---|---|---|
| 只拷 .obj 不拷贴图 | 查看器里变白模 | 贴图外链丢失，见 ch04 4.3 |
| glb 选"不内嵌"贴图 | 可能生成额外文件/丢贴图 | glb 优势就是内嵌，见 ch04 4.3 |
| 导出 stl 想保留颜色 | 颜色丢失 | stl 只有几何，见 ch04 4.1 |

## 常见问题

- 导出后是白模 → 贴图丢失/路径错，见 [ch04 4.3](../docs/ch04_formats.md#c04-03)
- 模型朝向不对 → 检查 Up 轴设置，见 [ch04 4.4](../docs/ch04_formats.md#c04-04)
- obj 打开没贴图 → .mtl 和图片没一起拷，见 4.3
- 其它 → [附录 C 故障排查](../../90_appendix/docs/appC_troubleshooting.md)
