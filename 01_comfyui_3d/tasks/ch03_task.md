# 实操 03：试一条文生 3D 路线

> 对应章节：[第 3 章 文生 3D](../docs/ch03_text2_3d.md) ｜ 预计耗时：60 分钟
> 状态：`[已完成]`

## 目标

体验文生 3D 的"直出"或"文生图→图生3D"路线，并与图生 3D（ch02）对比稳定性。
**本章选读：跑通优先，跑不动就重点体会决策逻辑。**

## 前提

- [ ] 已完成 ch02 图生 3D（知道基线是什么样）
- [ ] 有一个可用的文生 3D 方案/节点，或可用文生图（主仓库 ch03）+ 图生 3D 组合

## 步骤

1. **写结构提示词**：写一个描述物体的提示词，聚焦**外形和结构**（如"一个带细长颈的白色陶瓷花瓶，圆腹，平底"），
   不要堆"电影感/光效"这类 2D 词（见 [ch03 3.1](../docs/ch03_text2_3d.md#c03-01)）。

2. **选路线**（A/B 二选一或都试）：
   - **路线 A 直出**：把提示词送进文生 3D 节点 → 生成网格 → 导出
   - **路线 B 曲线**：先用文生图生成物体图 → 挑一张形状符合的 → 走 ch02 图生 3D → 导出

3. **运行并记录**：Queue，记录耗时/显存/是否成功。
   - 成功：导出 glb
   - 失败：记录报错，判断是否方案/显存/提示词问题

4. **对比稳定性**：同样描述，路线 A 和路线 B 各生成一次，对比哪个形状更符合描述、哪个更稳定。

5. **总结决策**：用一句话记下"这个场景下我会选哪条路、为什么"。

## 验收标准

- [ ] 至少跑通一条文生 3D 路线（或明确记录失败原因）
- [ ] 对比了文生 vs 图生的稳定性差异
- [ ] 填出决策总结

## 改一改会怎样（小实验）

| 改动 | 预期现象 | 为什么 |
|---|---|---|
| 提示词堆一堆"电影感光效" | 形状反而更不可控 | 文生3D提示词要重结构，见 ch03 3.1 |
| 路线 B 多换几张文生图再进3D | 更容易挑到好形状 | 先筛图再生成，成功率更高，见 ch03 3.3 |
| 用图生3D（ch02）对比 | 形状更可控 | 有参考约束，见 ch03 3.2 |

## 可复现记录

| 项 | 值 |
|---|---|
| 提示词 | |
| 选择路线 | A 直出 / B 曲线 |
| 耗时 / 显存 / 成功? | |
| 与图生3D对比 | 更稳 / 更不稳 |

## 常见问题

- 文生 3D 结果太随机 → 换路线 B（先文生图筛形状），见 [ch03 3.3](../docs/ch03_text2_3d.md#c03-03)
- 提示词不知怎么写 → 聚焦"形状、轮廓、各部分"，见 [ch03 3.1](../docs/ch03_text2_3d.md#c03-01)
- 显存爆 → 用轻量方案或换图生 3D
- 其它 → [附录 C 故障排查](../../90_appendix/docs/appC_troubleshooting.md)
