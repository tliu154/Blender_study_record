# 第 1 篇 ComfyUI 3D 建模（ComfyUI 3D Modeling）

前置：[ComfyUI 2D 基础](https://github.com/tliu154/ComfyUI_study_record)（ch01~ch08 概念）。
目标：在 ComfyUI 里用 AI 生成 3D 模型，理解 3D 表示，导出标准格式并衔接 [第 2 篇 Blender 基础](../02_blender_basics/README.md)。

**学完你能**：说出主流 3D 表示的区别、搭一条图生 3D 工作流、导出 glb/obj、知道 AI 模型在 Blender 里要做哪些后处理。

## 依赖

- 全篇依赖 ComfyUI 的 2D 概念（采样/提示词/模型加载）——通过超链引用姊妹仓库，不复制内容
- ch05 衔接 Blender 的 [ch07 导入](../02_blender_basics/docs/ch07_import.md) / [ch08 清理](../02_blender_basics/docs/ch08_mesh_cleanup.md) / [ch11 导出](../02_blender_basics/docs/ch11_export.md)

## 章节

**状态：[已完成] 5 章教学 + 5 份实操。**
章节清单、状态、预定文件一律见 [SYLLABUS 第 1 篇](../SYLLABUS.md)，此处不重复。

## 实践方向

- 用一张清晰的产品图跑通图生 3D，观察不同输入图对结果的影响
- 把生成的模型导出成 glb，导入 Blender 做最小清理再导出
- 对比图生 3D 与文生 3D 的适用场景
