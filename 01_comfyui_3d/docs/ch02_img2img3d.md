### 2.1 一张图怎么变 3D

**概念定义**：图生 3D 模型看过海量「图 + 对应 3D」数据，学会了「从单张图推测物体立体形状」的能力。
给它一张图，它生成一个 3D 表示（通常是网格或点云再转网格），
过程中会「脑补」看不见的背面——这也是为什么输入图质量和角度很关键。

**直觉类比**：像**看着一张照片捏泥人**——
照片只给你正面，背面长什么样得靠你猜（基于常识：杯子背面大概也是圆的）。
AI 也是这样：正面有参考所以准，背面靠"脑补"所以可能糙。
给它的照片越清晰、越能看出结构，猜得越准。

**界面 / 参数**：图生 3D 的常见输入/输出——
- **输入**：一张图（通常要求主体清晰、背景简单）
- **可选输入**：提示词（描述物体）、多视图（几个角度的图，进阶）
- **参数**：生成步数/质量档位、输出面数、是否生成贴图——随节点包不同
- **输出**：网格（Mesh），常带贴图，导出 glb/obj（[ch04](ch04_formats.md)）

**常见误区**：
- ❌「一张图能完美还原物体所有面」—— 不能。背面/被遮挡部分是 AI 猜的，多视图能改善。
- ❌「什么图都能生成好 3D」—— 模糊、多主体、强透视、复杂场景的图效果差（见 2.4）。

> **够用边界**：记住「图生 3D = 从图推测形状，正面准、背面靠猜」即可。
> 背后的 2D 扩散/3D 重建原理跳过。
> **和已有认知的差异**：2D 图生图是「图→图」，输入输出的维度一样；
> 图生 3D 是「2D→3D」，**升维**了，AI 必须脑补看不见的信息——这是本质区别。

### 2.2 主流方案对比

**概念定义**：ComfyUI 上常见的图生 3D 方案各有特点：有的快但简，有的质量高但吃资源，有的带贴图。
选哪个看你的设备和需求，不用全学。

**直觉类比**：像**不同型号的 3D 扫描仪**——
有的便携快速（TripoSR，几十秒出结果但精度一般），
有的高精度大块头（Hunyuan3D 等，质量好但要更好的显卡）。
按你的"预算（显存）"和"精度要求"挑。

**界面 / 参数**：常见方案对比（2026-11 视角，具体以当下社区为准）——
| 方案 | 特点 | 输出 | 门槛 |
|---|---|---|---|
| **TripoSR** | 快、轻量、好上手 | 无纹理网格为主 | 较低 |
| **Hunyuan3D** | 质量好、可带纹理 | 带贴图网格 | 较高 |
| **InstantMesh** | 多视图思路、质量不错 | 网格 + 纹理 | 中高 |
| **其它新方案** | 迭代快 | 各异 | 各异 |

> 注：3D 模型迭代非常快，2026 年新方案不断。这里只给**分类和选型思路**，
> 具体用哪个查当下社区推荐与节点仓库（[附录 D](../../90_appendix/README.md)）。

**常见误区**：
- ❌「一定要用最强的模型」—— 学习先用 TripoSR 这类轻量的跑通流程，再升级。
- ❌「方案名和教程对不上」—— 3D 节点生态比 2D 更散、改名更快，按你装的包为准。

> **够用边界**：知道「TripoSR 快而轻、Hunyuan3D/InstantMesh 质量高但重，按显存选」这个分类就够。
> 各方案的网络结构跳过。
> **和已有认知的差异**：2D 里 SD1.5 稳定用好几年；3D 领域**方案半年一换**，
> 保持"看分类、看当下推荐"的心态，别记死某个名字。

### 2.3 最小图生 3D 工作流

**概念定义**：最小图生 3D 工作流就是：加载模型 → 输入一张图 → 运行生成 → 得到 3D → 导出文件。
不同节点包细节不同，但骨架一致。

**直觉类比**：像**用扫描仪扫一个物件**——
开机（加载模型）→ 放上物件（输入图）→ 按扫描（运行）→ 取出模型（导出）。
环节比 2D 少但每步更重。

**界面 / 参数**：骨架思路（节点名随包版本变化，以实际为准）——
```
【加载】
Load 3D Model（如 TripoSR / Hunyuan3D 节点）→ 加载对应模型权重

【输入】
Load Image → 载入你的图（主体清晰、背景简单）

【生成】
Image-to-3D 节点：image + model → 输出 mesh / 3D 数据
（可选：填提示词描述、设质量/面数参数）

【导出】
Export/Save 3D（mesh）→ 导出 glb / obj（见 ch04）
```

**常见误区**：
- ❌「和文生图节点一样」—— 完全不同的一套节点，要先装 3D 节点包和模型。
- ❌「生成完就是最终模型」—— 直出的网格常有问题，要去 Blender 后处理（[ch05](ch05_handoff.md)）。
- ❌「节点名照抄教程」—— 3D 节点改名快，按你装的包为准。

> **够用边界**：知道「加载模型 → 输入图 → 生成 mesh → 导出 glb」这条骨架即可。
> 具体节点参数动手时查当前教程/模板。
> **和已有认知的差异**：这是你第一次在 ComfyUI 里**输出不是图片而是模型文件**，
> 下游从"存图"变成"导出 3D 文件 + 打开 Blender"。

### 2.4 输入图质量与结果的关系

**概念定义**：图生 3D 的质量**高度依赖输入图**。主体清晰、背景干净、角度明确的图能生成更好的模型；
模糊、多主体、强遮挡的图效果差。选图/处理图是提升结果最划算的一步。

**直觉类比**：像**拍照给师傅做雕塑**——
你给的照片越清楚、主体越突出、角度越正，师傅做得越像；
给一张糊的、里面有好几个东西的照片，师傅也懵。

**界面 / 参数**：什么样的图适合图生 3D——
| 要素 | 好图 | 差图 |
|---|---|---|
| 主体 | 单一、居中、完整 | 多个物体、被截断 |
| 背景 | 干净/纯色 | 杂乱 |
| 清晰度 | 高、细节可见 | 模糊、噪点 |
| 角度 | 接近正视角、能看出体积 | 强透视/极端角度 |
| 光照 | 均匀 | 强阴影遮挡结构 |

- 提升技巧：先用 2D 工具把主体抠出来、补背景，再送进图生 3D（可选进阶）
- 多视图：给几个角度的图能显著改善背面质量（方案见 2.2）

**常见误区**：
- ❌「随便截图就能生成好模型」—— 输入图是质量上限，垃圾输入出垃圾输出。
- ❌「生成不好就怪模型不行」—— 先检查输入图，很多时候换张图立竿见影。

> **够用边界**：记住「主体单一 + 背景干净 + 清晰正视角 = 好输入」，
> 结果不理想先换图再换模型。
> **和已有认知的差异**：2D 生成里提示词是主要控制手段；
> 图生 3D 里**输入图本身**成了最关键的控制因素——"选图"比"调参"更重要。

---

## 小结

- 图生 3D = 从一张图推测立体形状；正面有参考较准，背面靠 AI 脑补。
- 主流：TripoSR（快、轻）/ Hunyuan3D、InstantMesh（质量高、重）；按显存选，看当下推荐。
- 最小流程：加载模型 → 输入图 → 生成 mesh → 导出 glb；下游是模型文件不是图片。
- 输入图质量决定上限：主体单一、背景干净、清晰正视角；结果差先换图。
