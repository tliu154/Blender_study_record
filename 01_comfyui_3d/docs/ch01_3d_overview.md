### 1.1 3D 和 2D 生成有何不同

**概念定义**：2D 生成（SD/FLUX）输出的是一张**像素网格（image）**——宽×高的平面数组。
3D 生成输出的是**三维结构的数据**，常见是一个网格（Mesh）：由顶点、边、面组成，
可以在 3D 软件里旋转、缩放、打光、渲染，也能导出给游戏引擎或 3D 打印机用。

**直觉类比**：2D 生成像**画一张照片**——好看但只有这一个角度；
3D 生成像**捏一个真人手办**——你能把它拿在手里转着看、换姿势、放到不同场景里拍照。
手办比照片多了一个「立体」维度，也因此多了骨架（网格）、皮肤（贴图）、摆放（坐标）这些照片没有的东西。

**界面 / 参数**：3D 世界多出来的核心概念（先有个印象，后面章节逐个讲）——
- **网格（Mesh）**：模型的骨架，由顶点/边/面组成
- **UV 坐标**：把 2D 贴图「贴」到 3D 表面的映射（[ch09 UV](../../02_blender_basics/docs/ch09_uv.md)）
- **法线（Normal）**：每个面朝向哪，决定受光和正反（[ch08 清理](../../02_blender_basics/docs/ch08_mesh_cleanup.md)）
- **材质 / 贴图（Material / Texture）**：模型表面的颜色、粗糙度等（[ch10 材质](../../02_blender_basics/docs/ch10_materials.md)）
- **格式（glb / obj / fbx / stl）**：模型文件的打包方式（[ch04](ch04_formats.md)）

**常见误区**：
- ❌「3D 模型就是一张图加个深度」—— 不是。3D 是独立的几何数据结构，和像素图是两种东西。
- ❌「生成 3D 就能直接用于游戏/打印」—— AI 生成的模型常有问题（破面、法线乱、没有 UV），要后处理（[ch05](ch05_handoff.md)）。

> **够用边界**：记住「3D = 可从任意角度看的数据体，核心是网格 + 贴图 + 法线，需要后处理」即可。
> 3D 数学（变换矩阵、拓扑）不用碰。
> **和已有认知的差异**：你在 ComfyUI 2D 里熟悉的 `Save Image` 出的是图片；
> 3D 流程的下游是**模型文件 + 3D 软件**，整个工作流的"出口"变了。

### 1.2 常见 3D 表示（够用直觉）

**概念定义**：AI 生成 3D 有好几种「表示方式」，即「用什么形式存这个 3D 数据」。
不同模型/算法输出不同表示，最后大多转成网格（Mesh）给下游用。

**直觉类比**：同样是「记录一个物体」，有几种办法——
- **网格（Mesh）**：像用乐高积木拼出表面（顶点连成三角面），最通用
- **点云（Point Cloud）**：像撒一把沙子形成物体轮廓，只有点没有面
- **体素（Voxel）**：像用乐高方块填满体积（3D 版的像素）
- **NeRF / 3DGS**：像用一堆「从各个角度拍的照片 + 数学」隐式表示，渲染很强但不直接是网格
新接触只需知道「有这些类别」，不必深究。

**界面 / 参数**：常见表示与用途——
| 表示 | 特点 | 你会不会直接碰到 |
|---|---|---|
| **Mesh 网格** | 通用、可编辑、可导出 | **最常碰到**，最终目标 |
| **Point Cloud 点云** | 简单但没表面 | 某些模型输出，需转网格 |
| **Voxel 体素** | 规整但粗糙 | 少见 |
| **NeRF / 3DGS** | 渲染逼真、视角相关 | 前沿方案，通常要专门工具 |

**常见误区**：
- ❌「所有 AI 3D 都直接出 Mesh」—— 有些先出点云/隐式场，再转网格；中间步骤你看不到但存在。
- ❌「3DGS 能直接导进 Blender 当普通模型」—— 它是新式表示，要用专门插件/渲染器，不是标准网格流程。

> **够用边界**：知道「最终要的是 Mesh（网格），其它表示是中间态或前沿方案」就够。
> 各种表示的数学原理跳过。
> **和已有认知的差异**：2D 里你只处理一种数据（图像）；3D 里「数据长什么样」本身就是一个需要区分的概念。

### 1.3 ComfyUI 能做哪些 3D

**概念定义**：ComfyUI 通过**自定义节点**（[主仓库 ch24](https://github.com/tliu154/ComfyUI_study_record/blob/main/06_ecosystem/docs/ch24_manager.md)）接入各种 AI 3D 模型，
主流是两条路线：**图生 3D**（给一张图生成模型）和**文生 3D**（给文字生成模型）。
还有 3D 相关的辅助（多视图生成、模型后处理节点等）。

**直觉类比**：像选「做手办的起点」——
图生 3D 是**照着一张照片捏**（有参考，形状更可控）；
文生 3D 是**凭描述从零捏**（自由但更靠运气）。
两条路ComfyUI 都能走，只是用的节点/模型不同。

**界面 / 参数**：两条路线对比——
| 路线 | 输入 | 特点 | 本章节 |
|---|---|---|---|
| **图生 3D** | 一张图 | 形状可控、质量较稳，入门首选 | [ch02](ch02_img2img3d.md) |
| **文生 3D** | 文字提示词 | 自由但不稳定 | [ch03](ch03_text2_3d.md) |
| 多视图 / 辅助 | 多张角度图 | 进阶，提升质量 | 按需 |

- 3D 节点生态变化快，模型名/节点名以你安装时的版本为准（[附录 D](../../90_appendix/README.md) 的资源入口）
- 常见方案如 TripoSR（快）、Hunyuan3D、InstantMesh 等，对比见 [ch02 2.2](ch02_img2img3d.md#c02-02)

**常见误区**：
- ❌「ComfyUI 自带 3D 功能」—— 不。要装 3D 相关自定义节点和模型，比 2D 多一步配置。
- ❌「3D 生成和 2D 一样快」—— 3D 生成通常更慢、更吃显存，且后处理要额外开 Blender。

> **够用边界**：知道「ComfyUI 靠自定义节点做 3D，主流是图生/文生两条路，入门走图生」即可。
> 具体装哪个节点包，动手时查当下社区推荐。
> **和已有认知的差异**：2D 阶段核心节点是官方自带的；3D 阶段**几乎全靠社区节点**，
> 生态更散、迭代更快——要有"查当下方案"的心态，别死记某个模型名。

### 1.4 一条完整流程长什么样

**概念定义**：把前面串起来，一条「从想法到成品」的 3D 流程通常是：
`准备输入（图/文字）→ ComfyUI 生成 3D → 导出标准格式 → Blender 后处理 → 导出交付 / 渲染展示`。
本仓库就是按这条线组织：第 1 篇讲前半段，第 2 篇讲后半段。

**直觉类比**：像**拍电影的流程**——
ComfyUI 是「特效工厂」负责生成素材（3D 模型），
Blender 是「后期剪辑室」负责修素材、搭场景、出成片。
两步各司其职，中间用「标准格式（glb/obj）」交接，就像用通用文件格式传素材。

**界面 / 参数**：完整流程与各章对应——
```
① 输入准备：一张清晰的产品图 / 一段文字描述
② ComfyUI 生成：图生3D(ch02) 或 文生3D(ch03)
③ 导出：glb / obj / ply（ch04）—— 这是两个软件的"交接格式"
④ Blender 后处理（第2篇）：
   导入(ch07) → 检查/清理法线(ch08) → [需要时] UV(ch09)+材质(ch10) → 导出(ch11) / 渲染(ch12)
⑤ 交付：游戏引擎 / 3D打印 / 产品展示图
```

**常见误区**：
- ❌「ComfyUI 一条龙搞定」—— 目前 AI 生成的 3D 几乎都要去 Blender 修一遍，别指望直出可用。
- ❌「格式随便选」—— 不同用途要不同格式（引擎用 glb/fbx、打印用 stl），见 [ch04](ch04_formats.md)。

> **够用边界**：记住这条五步主线，知道自己"现在在哪一步、下一步去哪"就够。
> **和已有认知的差异**：2D 流程是「提示词 → 出图 → 存图」三步结束；
> 3D 是**跨软件的多阶段流程**，ComfyUI 和 Blender 各管一段——这是本篇最重要的整体认知。

---

## 小结

- 3D 生成出的是可从任意角度看的数据体（核心：网格 + 贴图 + 法线），不是平面像素图。
- 常见表示有 Mesh / 点云 / 体素 / NeRF / 3DGS；最终要的通常是 Mesh。
- ComfyUI 靠自定义节点做 3D，主流两条路：图生 3D（可控、入门首选）/ 文生 3D（自由但不稳）。
- 完整流程：输入 → ComfyUI 生成 → 导出格式 → Blender 后处理 → 交付；跨软件协作是核心特征。
