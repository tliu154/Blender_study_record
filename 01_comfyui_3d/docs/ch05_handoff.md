### 5.1 AI 生成模型常见问题

**概念定义**：ComfyUI 直出的 3D 模型常见几类问题：破面/洞、法线朝向乱、非流形边、
UV 缺失或乱、贴图丢失、面数过高。这些问题不影响"生成成功"，但影响能否用于引擎/打印/展示。
Blender 的后处理就是修这些。

**直觉类比**：像**工厂刚下线的毛坯件**——
形状大致有了，但毛刺（破面）、方向装反（法线）、没上漆（材质）、太笨重（面数高）。
得进"精加工车间"（Blender）打磨才能成品。

**界面 / 参数**：常见问题与对应修复章节——
| 问题 | 现象 | 修复 |
|---|---|---|
| 法线反/乱 | 模型发黑、内外颠倒 | [ch08 网格清理](../../02_blender_basics/docs/ch08_mesh_cleanup.md) |
| 破面 / 非流形 | 有洞、打印失败 | [ch08](../../02_blender_basics/docs/ch08_mesh_cleanup.md) |
| 面数过高 | 文件大、引擎卡 | Decimate 减面（[ch08](../../02_blender_basics/docs/ch08_mesh_cleanup.md)）|
| UV 缺失/乱 | 贴不上图或贴图错乱 | [ch09 UV](../../02_blender_basics/docs/ch09_uv.md) |
| 无贴图（白模）| 只有灰白几何 | [ch10 材质](../../02_blender_basics/docs/ch10_materials.md) |
| 贴图丢失 | 白模/粉红 | [ch04 4.3](ch04_formats.md#c04-03) + [ch10](../../02_blender_basics/docs/ch10_materials.md) |

**常见误区**：
- ❌「生成有问题=白做了」—— 不。绝大多数问题在 Blender 里可修，这是正常流程的一环。
- ❌「所有问题都要修」—— 按用途修：打印要封闭表面，展示要好看，引擎要低面数——够用即可。

> **够用边界**：知道「AI 出毛坯 → Blender 精修」的分工，能对号入座找到修复章节即可。
> **和已有认知的差异**：2D 出图基本"出图即成品"（最多放大/局部重绘）；
> 3D 是**出模型≠成品**，后处理是必需品而非可选项。

### 5.2 导入与初步检查

**概念定义**：把导出的 glb/obj 导入 Blender，先做初步检查——模型在不在、大小对不对、
朝向正不正、有没有明显破面。这一步决定后面要修什么。

**直觉类比**：像**收货验货**——
先拆箱看看东西在不在（模型导入成功没）、尺寸对不对（太小/太大）、
方向正不正（躺着/倒着）、外观有没有明显破损（破面）。

**界面 / 参数**：导入与检查流程（详见 [ch07 导入与检查](../../02_blender_basics/docs/ch07_import.md)）——
```
① 打开 Blender → 删掉默认立方体（避免混进场景）
② File > Import > glTF 2.0（或 obj）→ 选你的文件
③ 检查：
   - 视图里能看到模型吗？（按 Home 键"框选全部"快速定位）
   - 大小合适吗？（太小可用 `S` 放大，或看ch07 单位）
   - 朝向对吗？（从几个角度看）
   - 开线框/统计看面数、有无破面
```

**常见误区**：
- ❌「导入后看不见=文件坏了」—— 多半是模型太小/太远，按 `Home` 框选全部就能看到（[ch07](../../02_blender_basics/docs/ch07_import.md)）。
- ❌「忘了删默认立方体」—— 会混进场景，导出时一起带出去。

> **够用边界**：会「导入 + 按 Home 找到模型 + 看大小朝向」就够开始后处理。
> **和已有认知的差异**：这是你第一次在 Blender 里操作——若完全零基础，
> 先扫一眼 [ch06 界面与视图](../../02_blender_basics/docs/ch06_ui_navigation.md) 认识导航三件套再回来。

### 5.3 最小后处理链路

**概念定义**：不是所有问题都要修。给出一条「最小后处理链路」——
绝大多数 AI 模型走这几步就能用：检查 → 重算法线 → 修破面/减面 →（需要时）补材质 → 导出。

**直觉类比**：像**快餐式精修**——
不搞全套雕塑流程，只做"能让模型可用"的几步关键处理：摆正、修面、上色、出货。
追求的是够用，不是完美。

**界面 / 参数**：最小链路与超链——
```
① 导入 + 检查          → [ch07](../../02_blender_basics/docs/ch07_import.md)
② 重算法线（Shift+N）  → [ch08 8.2](../../02_blender_basics/docs/ch08_mesh_cleanup.md#c08-02)
③ 修破面 / 减面         → [ch08](../../02_blender_basics/docs/ch08_mesh_cleanup.md)
④ [需要时] 补 UV/材质  → [ch09 UV](../../02_blender_basics/docs/ch09_uv.md) + [ch10 材质](../../02_blender_basics/docs/ch10_materials.md)
⑤ 导出                 → [ch11 导出](../../02_blender_basics/docs/ch11_export.md)
⑥ [需要时] 渲染出图    → [ch12 渲染](../../02_blender_basics/docs/ch12_render.md)
```

**常见误区**：
- ❌「每一步都必做」—— 不是。白模且只交引擎，可能 ①②③⑤ 就够；要好看再补材质渲染。
- ❌「先把 Blender 全学完再动手」—— 不用。按这条链路用到哪章查哪章，边做边学。

> **够用边界**：记住这条最小链路，按顺序走、按需要跳，就是本仓库第 2 篇的使用方式。
> **和已有认知的差异**：这是"够用导向"学习法的体现——
> 不从头啃 Blender 教材，而是**按 3D 后处理的实际需要**按需取用第 2 篇章节。

### 5.4 导出交付

**概念定义**：后处理完成后，按最终用途从 Blender 导出：引擎用 fbx/glb、打印用 stl、展示用 glb 或直接渲染图。
这一步和第 4 章的"交接导出"不同——那次是为了进 Blender，这次是**最终交付**。

**直觉类比**：像**精加工完再打包发货**——
前面进车间（Blender）用的是一种包装（glb 交接），
成品出厂要按客户要求重新包装（引擎/打印/展示各有各的箱）。

**界面 / 参数**：最终交付格式（详见 [ch11 导出](../../02_blender_basics/docs/ch11_export.md)）——
| 最终用途 | 格式 | 备注 |
|---|---|---|
| 游戏引擎 | fbx / glb | 看引擎偏好 |
| 3D 打印 | stl | 确认封闭、法线朝外 |
| 网页/展示 | glb | 贴图内嵌 |
| 产品展示图 | 渲染出 png | [ch12 渲染](../../02_blender_basics/docs/ch12_render.md) |

**常见误区**：
- ❌「处理完直接覆盖原文件」—— 建议另存，保留 AI 原始模型方便回退重修。
- ❌「导出设置照搬上次」—— 不同用途设置不同（尤其打印要检查水密性）。

> **够用边界**：记住「最终按用途导出、另存保留原件、打印要验水密」三条即可。
> **和已有认知的差异**：到这里你走完了完整闭环——
> 从"AI 生成 3D"到"可用的成品"，跨了 ComfyUI 和 Blender 两个软件、多次导出。
> 这正是 3D 工作流和 2D 最大的不同。

---

## 小结

- AI 生成的是"毛坯"，几乎都要去 Blender 修——这是正常流程，不是失败。
- 常见问题（破面/法线/UV/贴图/面数）各有对应修复章节，按用途修、够用即可。
- 导入检查：删默认物体、导入 glb、按 Home 找到模型（看不见多半是太小/太远）。
- 最小后处理链路：检查 → 重算法线 → 修面/减面 →（需要时）补材质 → 导出 →（需要时）渲染。
- 最终按用途导出，另存保留原件。
