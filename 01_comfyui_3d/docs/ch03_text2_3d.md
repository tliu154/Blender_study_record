### 3.1 只用文字能生成 3D 吗

**概念定义**：能。文生 3D 模型从海量「文字 + 3D」或「文字 + 图 + 3D」数据学习，
输入一段描述（如"一个红色的陶瓷花瓶"），输出对应 3D 模型。
常见两条技术路线：**大模型直接生成 3D**，或**先生成多视图图再转 3D**（把文生 3D 拆成"文生图 + 图生 3D"）。

**直觉类比**：像**只看文字描述捏泥人**——
师傅没见过实物，只能凭"红色的陶瓷花瓶"这句话想象着捏。
自由度高（什么都能要求），但"像不像"全靠师傅的理解和功力——比照着照片捏（图生）更难控制。

**界面 / 参数**：文生 3D 常见输入/输出——
- **输入**：文字提示词（描述物体外形、材质、风格）
- **可选**：先文生图（用 SD/FLUX）得到一张图，再走图生 3D——这条"曲线救国"路线往往更稳
- **参数**：提示词、生成质量/步数、输出面数——随方案不同
- **输出**：网格（Mesh），导出 glb/obj

**常见误区**：
- ❌「文生 3D 一定比图生 3D 高级」—— 不是，只是不同起点；文生更自由但更不稳。
- ❌「提示词写得越花越好」—— 3D 提示词应**聚焦外形和结构**，堆砌风格词未必有用。

> **够用边界**：记住「文生 3D = 文字→模型，更自由但不稳；常借助'先文生图再图生 3D'的路线」即可。
> Score Distillation 等训练原理跳过。
> **和已有认知的差异**：你在 2D 里写提示词控制画面；文生 3D 的提示词要**描述立体结构**
> （形状、轮廓、各部分），而不是"光影氛围"这类 2D 常用词。

### 3.2 文生 vs 图生的取舍

**概念定义**：两条路线没有绝对优劣，按你的**有没有参考图**和**要控形状还是求创意**来选。

**直觉类比**：——
- **有参考图、要像某个具体东西** → 走图生 3D（照着照片捏，形状可控）
- **没图、天马行空要个创意造型** → 走文生 3D（凭描述捏，自由但不稳）
- **介于两者之间** → 先文生图，挑一张满意的，再图生 3D（兼顾自由与可控，实用推荐）

**界面 / 参数**：对比表——
| 维度 | 图生 3D | 文生 3D |
|---|---|---|
| 输入 | 一张图 | 文字 |
| 形状可控性 | 高（有参考）| 低（靠猜）|
| 自由度 | 受限于参考图 | 高 |
| 稳定性 | 较稳 | 较不稳 |
| 适合 | 具体物体、复刻 | 创意、概念探索 |
| 入门推荐 | ✅ 首选 | 进阶 |

**常见误区**：
- ❌「文生 3D 不需要图所以更简单」—— 恰恰相反，没有参考约束，结果更难预测。
- ❌「必须先学文生 3D」—— 不，图生 3D 更可控，才是入门首选。

> **够用边界**：记住「有图走图生、无图求创意走文生、想兼顾就'文生图→图生3D'」这条决策口诀。
> **和已有认知的差异**：2D 里文生图和图生图是平行功能；3D 里**图生是主力、文生是补充**，
> 因为形状控制对 3D 更重要。

### 3.3 最小文生 3D 流程

**概念定义**：最小文生 3D 流程骨架：写提示词 →（可选先文生图）→ 文生 3D 节点生成 → 导出。
两条子路线都给出来，按你的方案选。

**直觉类比**：两条路——
**路线 A（直出）**：直接把描述交给 3D 模型，像"口头定制"。
**路线 B（曲线）**：先把描述变成一张图（挑满意的），再照图生成 3D，像"先看设计稿再做实物"——多一步但更可控。

**界面 / 参数**：骨架思路（节点名随方案变化）——
```
【路线 A：文生 3D 直出】
写提示词（聚焦外形/结构）→ Text-to-3D 节点 → 网格 → 导出 glb

【路线 B：文生图 → 图生 3D（推荐，更可控）】
① 文生图（SD/FLUX，见主仓库 ch03）→ 得到一张物体图
② 挑一张形状符合预期的图
③ 走 ch02 的图生 3D 流程 → 网格 → 导出 glb
```

**常见误区**：
- ❌「路线 B 是多此一举」—— 不是。先出图能**筛掉不满意的形状**，再进 3D 成功率高很多。
- ❌「文生 3D 提示词照抄 2D 的」—— 要改成描述结构/外形，见 3.1。

> **够用边界**：知道有"直出"和"文生图→图生3D"两条路、后者更可控即可。
> 具体节点参数动手时查当前方案。
> **和已有认知的差异**：你熟悉的文生图流程在这里成了**文生 3D 的前置步骤**——
> 2D 技能在 3D 流程里以"曲线路线"的方式复用上了。

<a id="c03-04"></a>

### 3.4 什么时候用哪条路

**概念定义**：把前面做个决策总结，方便你按场景快速选路。

**直觉类比**：像**出门选交通工具**——
近且有明确目的地（有参考图）→ 走路/公交（图生 3D，直接可控）；
远且想探索（无图求创意）→ 自驾（文生 3D，自由但要自己掌方向）；
想稳妥到达新地方 → 先查地图定路线再走（文生图→图生 3D）。

**界面 / 参数**：决策表——
| 你的情况 | 推荐路线 |
|---|---|
| 有清晰参考图 | 图生 3D（ch02）|
| 无图，但要具体常见物体 | 文生图 → 图生 3D（ch03 路线 B）|
| 无图，要创意/概念造型 | 文生 3D 直出（ch03 路线 A）|
| 结果总不理想 | 回到图生 3D + 优化输入图（ch02 2.4）|

**常见误区**：
- ❌「一条路走到黑」—— 3D 生成不确定性高，多试几条路、多换输入是常态。
- ❌「第一次就要完美模型」—— 先跑通、再迭代；后处理在 Blender（ch05）还能救。

> **够用边界**：把这张决策表记心里，遇到任务先对号入座选起点。
> **和已有认知的差异**：2D 流程选择相对固定；3D 里**"选对起点路线"本身就是一门功课**，
> 这也是为什么本章标 `[选读]`——先把图生 3D 走熟，再回来权衡。

---

## 小结

- 文生 3D = 文字→模型，更自由但更不稳；提示词要描述外形结构，不是 2D 的光影氛围。
- 两条路线：直出（自由）/ 先文生图再图生 3D（更可控，实用推荐）。
- 决策口诀：有图走图生、无图求创意走文生、想兼顾就"文生图→图生3D"。
- 本章选读：先掌握图生 3D，再来看文生这条补充路线。
