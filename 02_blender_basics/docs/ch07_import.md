### 7.1 导入 AI 生成的模型

**概念定义**：用 Blender 的 `File > Import` 菜单把外部 3D 文件读进当前场景。
常用 glTF 2.0（glb/gltf）和 Wavefront（obj）。导入后模型作为一个物体出现在场景里。

**直觉类比**：像**把快递件拆进房间**——
打开门（File > Import）、选对箱子类型（glb/obj）、把东西放进屋（场景）。
放进来后它就是你场景里的一个物体，可以选中、移动、修改。

**界面 / 参数**：导入步骤——
```
① 打开 Blender → 先把默认立方体删掉：
   大纲视图选中 Cube → 按 X → 确认删除（不删会混进场景）
② File > Import > glTF 2.0（导入 glb/gltf）
   或 File > Import > Wavefront (.obj)（导入 obj）
③ 文件浏览器里选你的文件 → Import
④ 导入后按 Home 框选全部，找到模型
```
- 导入 glb 时可以在右侧选项里看到"内嵌贴图会被提取"之类信息（glb 带贴图，见 [ch04 4.3](../../01_comfyui_3d/docs/ch04_formats.md#c04-03)）

**常见误区**：
- ❌「忘记删默认立方体」—— 导出时会一起带出去，多出个方块。
- ❌「导 obj 只有 .obj 没贴图文件」—— 贴图会丢（白模），要把 .obj/.mtl/图片放一起（见 [ch04 4.3](../../01_comfyui_3d/docs/ch04_formats.md#c04-03)）。
- ❌「Import 菜单里找不到 glTF」—— 老版本 Blender 可能要启用插件；新版内置。

> **够用边界**：会「删默认物体 → File > Import → 选格式 → 导入 → Home 找模型」这条流程即可。
> **和已有认知的差异**：ComfyUI 里"加载模型"是加载神经网络权重；
> Blender 里"导入模型"是把 3D 几何文件读进场景——两个"模型"含义不同（见 [NOTATION](../../NOTATION.md) 易混词）。

### 7.2 检查模型是否正常

**概念定义**：导入后快速检查几项：模型在不在、面数多少、有没有明显破面、
法线方向对不对（是否发黑）、贴图在不在。这决定后续要做哪些修复。

**直觉类比**：像**收货验货**——
先看清数量（面数）、有没有破损（破面）、方向对不对（法线/朝向）、
外观对不对（贴图）。发现问题记下来，逐项处理。

**界面 / 参数**：检查方法——
- **看整体**：`Home` 框选全部；中键转到各角度观察
- **看面数**：选中物体 → 属性面板最下方有三角面数统计（或在编辑模式 `A` 全选看计数器）
- **看破面**：编辑模式（`Tab`）切到面（`3`），观察有没有缺面/洞
- **看法线**：视图叠加层（右上角球图标下拉）勾选 `Face Orientation`（面朝向）——蓝色为正面、红色为反面，红色多说明法线反了（修复见 [ch08](ch08_mesh_cleanup.md)）
- **看贴图**：切到 `Material Preview` 着色模式（视图右上角四个球图标之一），看有没有贴图/颜色

**常见误区**：
- ❌「视图是灰白的就是没贴图」—— 可能只是处于 `Solid`（实体）着色模式，切到 `Material Preview` 再看。
- ❌「模型发黑就是坏了」—— 多半是法线反了，Shift+N 能救（见 [ch08 8.2](ch08_mesh_cleanup.md#c08-02)）。

> **够用边界**：会看「在不在 / 面数 / 破面 / 法线（Face Orientation）/ 贴图（Material Preview）」这几项即可。
> **和已有认知的差异**：2D 出图看一眼就知道好坏；
> 3D 模型要**转着看、切着色模式看、开叠加层看**——检查是多角度、多模式的。

### 7.3 朝向/缩放/位置修正

**概念定义**：AI 生成的模型常有朝向歪、尺寸怪、不在原点的问题。
在**物体模式**下用 `G`（移动）/`R`（旋转）/`S`（缩放）整体调整，必要时 `Ctrl+A` 应用变换固化。

**直觉类比**：像**把一件东西摆正放稳**——
挪到桌子中间（位置）、转个方向让它直立（朝向）、放大到合适尺寸（缩放）。
这些都是"整体"操作，不拆开模型。

**界面 / 参数**：——
- **移动**：`G` + 鼠标 → 回车确认；想精确可 `G` 后跟 `X/Y/Z` 限定轴向
- **旋转**：`R` + 鼠标；`R` `X` `90` 表示绕 X 轴转 90 度
- **缩放**：`S` + 鼠标；`S` 后输入数字精确缩放（如 `S` `2` 放大两倍）
- **移到原点**：`Alt+G` 清除位置（回原点）；`Alt+R` 清旋转；`Alt+S` 清缩放
- **应用变换**：`Ctrl+A` → Scale/Rotation，把当前缩放旋转固化进网格（导出前常做，见 [ch06 6.4](ch06_ui_navigation.md#c06-04) 和 [ch11](ch11_export.md)）

**常见误区**：
- ❌「模型躺着/倒着就不管」—— 导出到引擎/打印会有问题，先摆正。
- ❌「S 放大了但导出还是原样」—— 没 `Ctrl+A` 应用缩放，见 ch06 6.4。

> **够用边界**：会 `G/R/S` 整体调整 + `Ctrl+A` 应用变换即可应付大多数"摆正放稳"需求。
> **和已有认知的差异**：这些 G/R/S 和 ComfyUI 无关，是 Blender 的通用操作；
> 记住"改整体在物体模式、改网格内部在编辑模式"（见 [ch06 6.3](ch06_ui_navigation.md#c06-03)）。

### 7.4 常见问题：模型太小/看不见

**概念定义**：导入后"屏幕上什么都没有"是新手最常见的惊慌时刻，
通常不是文件坏了，而是模型太小、离原点太远、或在视野外。几个办法快速定位。

**直觉类比**：像**在黑暗大操场上找一粒芝麻**——
东西在，只是太小又不在你眼前。办法：全局拉近（Home）、只看它（Frame Selected）、或放大它（S）。

**界面 / 参数**：排查顺序——
1. **按 `Home`**：框选全部，让软件把场景内容怼进视野
2. **看大纲视图**：模型名字在不在？在说明导入成功；点名字选中后小键盘 `.` 聚焦（Frame Selected）
3. **太小**：选中后 `S` 放大（如 `S` `100` 放大百倍）；或看属性面板物体的位置/缩放数值
4. **隐藏了**：大纲视图里眼睛图标是否关闭？网格图标（视口可见性）是否关了？
5. **真的坏了**：换一个已知能用的 glb 测试，确认是不是文件问题

**常见误区**：
- ❌「看不见=导入失败」—— 先按 Home，90% 能解决。
- ❌「反复重新导入」—— 先排查可见性和尺度，别急着重来。

> **够用边界**：记住排查顺序「Home → 看大纲 → 放大 → 查可见性」，能找回绝大多数"丢失"的模型。
> **和已有认知的差异**：2D 里图看不见就是没加载；3D 里"看不见"更多是**视角/尺度**问题，
> 模型其实好好地在场景里——这是 3D 特有的调试思路。

---

## 小结

- 导入：删默认立方体 → File > Import（glTF/obj）→ Home 找模型。
- 检查六项：在不在 / 面数 / 破面 / 法线（Face Orientation）/ 贴图（Material Preview）/ 朝向尺度。
- 修正：物体模式 `G/R/S` 摆正放稳，`Ctrl+A` 应用变换固化。
- 看不见别慌：Home → 看大纲 → 放大 → 查可见性，多半不是文件坏。
