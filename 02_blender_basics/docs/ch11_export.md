### 11.1 导出前检查清单

**概念定义**：导出前过一遍清单，避免"导出去才发现有问题"——
法线朝外、无多余物体、变换已应用、尺度单位对、材质贴图就位。

**直觉类比**：像**发货前验货打包**——
检查品质（法线/破面）、别把杂物塞进箱（默认立方体）、
标签尺寸对（变换/单位）、说明书齐（贴图）——确认再封箱发货。

**界面 / 参数**：checklist——
- [ ] 只选中要导出的物体（别把默认立方体/灯光/相机一起导出）
- [ ] 法线朝外（[ch08 8.2](ch08_mesh_cleanup.md#c08-02)，Face Orientation 蓝色为主）
- [ ] 变换已应用：`Ctrl+A` → Rotation & Scale（[ch07 7.3](ch07_import.md#c07-03)）
- [ ] 尺度合理：模型大小符合目标（打印看毫米、引擎看单位约定）
- [ ] 材质贴图就位、路径有效或已打包（[ch10](ch10_materials.md)）
- [ ] （打印专用）网格封闭、无非流形——stl 要求水密

**常见误区**：
- ❌「全选导出省事」—— 会把默认物体/辅助物一起带出去，只选目标物体。
- ❌「忘了 Apply Scale」—— 下游看到的尺寸可能和你 Blender 里不一样。

> **够用边界**：养成导出前过一遍这份清单的习惯即可。
> **和已有认知的差异**：第 4 章导出是"给 Blender 送毛坯"，本章是"从 Blender 发成品"——
> 两次导出的目的、检查项都不同，别混为一谈。

### 11.2 glb/gltf 导出设置

**概念定义**：glb 是最通用的交付格式（几何+材质+贴图单文件），导出时几个关键设置要认识：
Format（glb 单文件 / gltf 分离）、是否包含材质/贴图、应用修改器、正方向轴。

**直觉类比**：像**填快递单**——
选箱子类型（glb/gltf）、声明里面装不装说明书（贴图）、
按对方要求标注"此面朝上"（Up 轴）——填对了对方才能正确拆用。

**界面 / 参数**：`File > Export > glTF 2.0` 常用选项——
| 选项 | 建议 | 说明 |
|---|---|---|
| **Format** | `GLB` | 单文件，最省事；gltf 会分离出贴图文件 |
| **Include > Materials / Textures** | 勾选 | 带材质贴图 |
| **Apply Modifiers** | 勾选 | 让 Decimate 等修改器生效 |
| **+Y Up** | 视目标 | Blender Z-up，很多引擎要 Y-up；按目标调 |
| **Selection Only** | 按需勾选 | 只导出选中的物体 |
| **Transform > +Y Up** | 同上 | 坐标朝向 |

**常见误区**：
- ❌「勾了 Apply Modifiers 模型会永久改变」—— 不。只影响导出的文件，Blender 里的修改器还在。
- ❌「导出到引擎朝向错了不管」—— Up 轴要按目标引擎设置，否则模型躺着/倒着。

> **够用边界**：记住「Format 选 GLB、勾材质贴图 + Apply Modifiers、按目标设 +Y Up」几项即可。
> **和已有认知的差异**：2D 导出 png 几乎没选项；
> 3D 导出有一堆设置，每项都可能影响下游——所以要按清单逐项确认。

### 11.3 按用途选格式

**概念定义**：不同下游用途偏好不同格式。回顾第 4 章的选择，这里从 Blender 导出的最终决策再确认一次。

**直觉类比**：像**同一件产品发往不同客户，用不同包装**：
给网页/展示用通用箱（glb）、给游戏公司用他们的标准箱（fbx）、给打印店用只要形状的简装（stl）。

**界面 / 参数**：——
| 最终用途 | 导出格式 | Blender 操作 |
|---|---|---|
| 网页 / 展示 / 通用 | glb | File > Export > glTF 2.0 (GLB) |
| 游戏引擎（Unity/UE）| fbx / glb | File > Export > FBX 或 glTF，看引擎偏好 |
| 3D 打印 | stl | File > Export > STL，确认封闭水密 |
| 兼容老软件 | obj | File > Export > Wavefront (.obj)，贴图另带 |
| 渲染出图（非模型）| png | 用 ch12 渲染，不用导出模型 |

**常见误区**：
- ❌「一个格式走天下」—— 打印要 stl、引擎可能要 fbx，按对方要求来。
- ❌「导出 fbx 就不用管设置了」—— fbx 也有轴向/缩放/贴图设置，同样要确认。

> **够用边界**：记住「展示 glb、引擎 fbx/glb、打印 stl」的对应关系即可（同 [ch04 4.2](../../01_comfyui_3d/docs/ch04_formats.md#c04-02)）。
> **和已有认知的差异**：这里再次体现"同一模型导出多次"——
> 按不同交付用途导出不同格式，是 3D 工作流常态。

<a id="c11-04"></a>

### 11.4 贴图嵌入与常见坑

**概念定义**：导出时贴图能不能正确跟着走、有没有丢，是高频坑。glb 能内嵌贴图（推荐），
obj/fbx 常外链。导出后务必在查看器里验证。

**直觉类比**：像**寄件时确认说明书在不在箱里**——
glb 把说明书（贴图）封进箱（单文件），到货一定有；
外链格式说明书另寄，少一件对方就看到"白模/粉红"。

**界面 / 参数**：常见坑与处理——
| 坑 | 现象 | 处理 |
|---|---|---|
| 贴图丢失 | 白模 / 粉红 | glb 勾内嵌贴图；obj 连贴图文件一起给 |
| 修改器没生效 | 减面/处理没体现在导出里 | 勾 Apply Modifiers |
| 朝向错 | 引擎里躺着/倒着 | 调 +Y Up / 导出轴向 |
| 尺度错 | 模型巨大/极小 | 导出前 Apply Scale + 单位设置 |
| 法线反 | 导出发黑 | 导出前修法线（ch08）|

- 导出后验证：用 glTF 查看器 / 重新导入 Blender / 目标软件打开，确认外观和尺度

**常见误区**：
- ❌「导出成功就没事」—— 一定要在目标软件/查看器里打开验证，别只看"文件生成了"。
- ❌「粉红色是材质好看」—— 粉红通常意味着贴图缺失/路径错。

> **够用边界**：记住「glb 内嵌贴图、勾 Apply Modifiers、导出后在查看器验证」三条即可。
> **和已有认知的差异**：2D 存 png 基本所见即所得；
> 3D 导出"生成文件"和"在别处正确显示"是两回事——**验证**是必要步骤。

## 小结

- 导出前清单：只选目标物体、法线朝外、Apply 变换、尺度对、贴图就位、打印要水密。
- glb 导出关键设置：Format=GLB、带材质贴图、Apply Modifiers、按目标设 +Y Up。
- 按用途选：展示 glb、引擎 fbx/glb、打印 stl。
- 贴图：glb 内嵌最省事；导出后一定在查看器验证——粉红/白模=贴图丢失。
