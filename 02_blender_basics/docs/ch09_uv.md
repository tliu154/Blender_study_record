### 9.1 UV 解决什么问题

**概念定义**：贴图是 2D 图片，模型是 3D 表面。**UV 坐标**记录了"3D 表面每个点对应贴图上的哪个位置"，
是把 2D 贴图贴到 3D 上的桥梁。没有 UV，软件不知道图该怎么往模型上贴。

**直觉类比**：像**给地球仪贴世界地图**——
地图是平的（2D 贴图），地球仪是球的（3D 模型）。
要把平的地图服帖地包到球上，得先规划"哪块地图贴到球的哪块"——这个"规划"就是 UV 展开。
展开做得好，地图不变形；做不好，南极被拉成一条线。

**界面 / 参数**：——
- **U/V**：贴图的二维坐标轴（区别于 3D 的 X/Y/Z）
- **UV 岛（Island）**：摊平后的一块块面片，像把地球仪表面剪开摊在地上的碎片
- 每个顶点都有 UV 坐标；UV 编辑器里看到的就是摊平后的网格

**常见误区**：
- ❌「UV 是模型的一部分几何」—— 不是。UV 是"映射信息"，不影响模型形状，只影响贴图怎么贴。
- ❌「有贴图就不用管 UV」—— 贴图要靠 UV 才能贴上去，UV 乱贴图就乱。

> **够用边界**：记住「UV = 3D 表面到 2D 贴图的映射，为了贴图不扭曲」即可。
> UV 的数学/展开算法跳过。
> **和已有认知的差异**：2D 里图片直接铺满画布，无需映射；
> 3D 里"把图贴到立体表面"必须先有 UV——这是 3D 特有的中间步骤。

### 9.2 UV 编辑器与布局

**概念定义**：UV 编辑器是专门看/编辑 UV 的窗口，显示摊平后的网格叠在贴图方格上。
做 3D 后处理时， mostly 只需会看一眼 UV 是否合理，需要时用自动展开重做。

**直觉类比**：像**裁缝的排版台**——
把布料的各个裁片（UV 岛）摊在桌上（0~1 的方格=一张贴图），
看有没有叠在一起（重叠会导致贴图错乱）、有没有挤成一团（浪费贴图空间）。

**界面 / 参数**：——
- 切换工作区：顶部 `UV Editing` 工作区，或把一个区域改成 `UV Editor`
- UV 编辑器里：0~1 的方格代表一张贴图；网格岛摊在上面
- 理想状态：UV 岛**不重叠**、尽量铺满方格、变形小
- 与 3D 视图联动：在 UV 编辑器选中面，3D 视图对应面也高亮

**常见误区**：
- ❌「UV 岛重叠没关系」—— 重叠部分会贴同一块图，造成错乱（除非刻意做镜像对称）。
- ❌「UV 必须铺满 0~1」—— 不强制，但利用率低会浪费贴图分辨率。

> **够用边界**：会打开 UV 编辑器、看懂"UV 岛有没有重叠/挤一团"即可。
> 手动精修 UV 排布是进阶，本篇不做。
> **和已有认知的差异**：这是第三个"视图"（前两个是 3D 视图/大纲/属性），
> 专门看 2D 映射——Blender 不同任务用不同编辑器，这也是它的工作方式。

### 9.3 自动展开够用流程

**概念定义**：对 AI 模型，绝大多数时候用**自动展开**（Smart UV Project）就够——
软件自动把模型表面切成岛并摊平。手动标记缝合边精修是进阶，够用场景可跳过。

**直觉类比**：像**用"自动裁剪"功能裁衣服**——
机器自动把布料拆成片铺好，快且够用；高级裁缝才手动规划每刀怎么裁（标记缝合边）。
咱们做后处理，自动裁剪足矣。

**界面 / 参数**：——
```
① 选中模型 → Tab 进编辑模式 → A 全选
② 打开 UV 编辑器看现状（乱/重叠就需要重展）
③ U 键 → Smart UV Project（智能 UV 投射）→ 确认/调参数（岛间距等）
④ 看摊平结果：不重叠、分布合理即可
⑤ 之后去 ch10 加材质/贴图
```
- `U` 键是 UV 映射菜单，Smart UV Project 是最省事的自动展开
- `Mark Seam`（标记缝合边，Ctrl+E）是手动控制"从哪剪开"的进阶手段

**常见误区**：
- ❌「Smart UV Project 适合所有情况」—— 它会产生较多 UV 岛，可能有接缝；要求高时手动展开更好。
- ❌「重展 UV 会改模型形状」—— 不会，只改映射，模型几何不变。

> **够用边界**：会「编辑模式全选 → U → Smart UV Project」这一招，够应付大多数"UV 乱要重展"的场景。
> **和已有认知的差异**：这又是 Blender "一键自动"和"手动精修"两条路的体现——
> 够用优先，追求极致再学手动。

### 9.4 AI 模型何时需要重展

**概念定义**：不是所有 AI 模型都要重展 UV。判断标准：
**有可用贴图且显示正常** → 不用动；**白模要自己贴图** → 需要 UV；
**UV 乱导致贴图错乱** → 重展。先判断，别手贱重展把好 UV 弄坏。

**直觉类比**：像**衣服要不要重新裁**——
已经合身好看的衣服（有贴图且正常）别乱动；
要换新布料（自己贴图）才需要裁剪（UV）；
裁剪得乱七八糟穿不了（UV 错乱）才重做。

**界面 / 参数**：决策表——
| 情况 | 是否重展 UV |
|---|---|
| 模型自带贴图，显示正常 | ❌ 不用，别动 |
| 白模，要自己贴 2D 贴图 | ✅ 需要 |
| 贴图错乱/拉伸严重 | ✅ 重展 |
| 只用纯色材质/单色 | ❌ 用不上贴图，可不管 UV |
| 要烘焙/高级材质 | 进阶时再精修 |

**常见误区**：
- ❌「每个模型都要重展 UV」—— 不。有正常 UV 就别动，重展会丢掉原有贴图对应关系。
- ❌「白模一定要 UV」—— 只用纯色材质不需要；要贴图片才需要。

> **够用边界**：记住「有正常贴图别动 UV，自己贴图/贴图乱才重展」这条判断即可。
> **和已有认知的差异**：这是"够用导向"的体现——
> 不是每个概念都要用上，先判断"需不需要"再动手。

## 小结

- UV = 3D 表面到 2D 贴图的映射，为了把图正确贴到模型上（像地图包地球仪）。
- UV 编辑器看摊平网格；理想是 UV 岛不重叠、分布合理。
- 自动展开够用：编辑模式全选 → `U` → Smart UV Project。
- 判断再动手：有正常贴图别重展，白模要贴图/贴图乱才重展。
