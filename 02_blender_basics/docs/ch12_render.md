### 12.1 给模型拍张照

**概念定义**：渲染的最小要素：**相机（Camera）**决定从哪拍、拍多大范围；
**灯光/世界环境**提供照明；**渲染引擎**把场景计算成图片；**输出设置**决定分辨率和保存位置。
四样齐了就能出图。

**直觉类比**：像**用实体相机拍产品照**——
先摆好相机位置和角度（相机），布置灯光或用自然光（灯光/世界），
选拍照模式（引擎），设定照片尺寸并按下快门（输出/渲染）。
和摄影一模一样，只是在电脑里。

**界面 / 参数**：最小出图流程——
```
① 加相机：Shift+A → Camera，摆到合适位置角度
   （快速：选中模型，小键盘0 让视图对齐相机；或 View > Align View）
② 加灯光：Shift+A → Light → Area（面光最常用），放模型上方前方
③ 选引擎：属性面板相机图标（渲染）→ Render Engine 选 Eevee
④ 设输出：输出图标 → 分辨率（如 1080×1080）、格式 PNG、保存路径
⑤ 出图：把视图切到相机视角（小键盘0）→ F12 渲染 → 渲染完 Image > Save As
```

**常见误区**：
- ❌「没有相机也能渲染」—— 需要一台相机，否则报错。
- ❌「全黑一片」—— 没灯光/世界太暗，见 12.2。

> **够用边界**：记住「相机 + 灯光 + 引擎 + 输出 → F12 出图」这条最小流程即可。
> **和已有认知的差异**：ComfyUI 2D 生成是"从噪声算图"；
> Blender 渲染是"把已有 3D 场景拍成图"——一个凭空生成、一个真实拍摄，本质不同。

### 12.2 相机与灯光基础

**概念定义**：**相机**的位置/焦距决定构图和透视；**灯光**的类型/强度/位置决定明暗和质感。
够用场景：一台相机 + 一到两盏面光（Area Light）就能出不错的产品图。

**直觉类比**：像**产品摄影的布光**——
相机对准主体（构图），主灯打亮正面、补灯减弱阴影（布光）。
好照片七成靠光，模型再好没打光也白搭。

**界面 / 参数**：——
- **相机**：`Shift+A` → Camera；选中小键盘 `0` 切到相机视角；`G/R/S` 调整位置角度
  - 焦距（Lens）：数值大=长焦（透视弱）、小=广角（透视强），产品图常用 50mm 左右
- **灯光**：`Shift+A` → Light → **Area**（面光，柔和，最常用）；`S` 调大小、属性面板调 Energy（强度）
  - 三点布光：主光（Key）+ 补光（Fill）+ 轮廓光（Rim）——进阶，先一盏主光起步
- **世界环境（World）**：属性面板世界图标 → 调 Background 颜色/强度，给整体环境光
- **HDRI**：用一张环境贴图当光照，一键出高级感——进阶（占位 [ch14 灯光](ch14_lighting.md)）

**常见误区**：
- ❌「灯越亮越好」—— 过曝会丢失细节，适量并配合世界环境光。
- ❌「渲染全黑就加大灯」—— 先看有没有灯、相机是不是被物体挡住、世界是不是纯黑。

> **够用边界**：会「加相机 + 加一盏面光 + 调世界强度」出一张看得过去的图即可。
> 布光艺术是进阶（占位 ch14）。
> **和已有认知的差异**：2D 生成用提示词描述"电影感光效"；
> 3D 渲染的光是**真实摆放的灯**——要自己动手布，不能只靠文字。

### 12.3 Eevee/Cycles 怎么选

**概念定义**：Blender 两大渲染引擎——
**Eevee**（实时渲染，快，质量够用）和 **Cycles**（光线追踪，慢，质量高、真实光影）。
做 3D 后处理的产品展示，多数情况 Eevee 够用且快。

**直觉类比**：像**手机拍照 vs 专业单反**——
Eevee 像手机：随手拍、快、够发朋友圈（展示/预览）；
Cycles 像单反：慢、要架三脚架，但画质和光影真实（追求品质）。
按需要的"画质"和能等的"时间"选。

**界面 / 参数**：对比——
| 引擎 | 速度 | 质量 | 适合 |
|---|---|---|---|
| **Eevee** | 快（秒级）| 够用 | 预览、展示图、快出图 |
| **Cycles** | 慢（分钟级）| 高、真实光影 | 追求品质的成品图 |

- 切换：属性面板渲染图标 → Render Engine 下拉
- Cycles 可调采样数（Samples）：越高越干净但越慢；有降噪（Denoise）可少采样
- 新手建议：先用 Eevee 出图，够用就不折腾 Cycles

**常见误区**：
- ❌「Cycles 一定比 Eevee 好」—— 质量高但慢；展示用途 Eevee 常常足够。
- ❌「Cycles 有噪点就是坏了」—— 采样不足正常，加采样或开降噪。

> **够用边界**：记住「快出图用 Eevee、追求真实光影用 Cycles」这个二选一即可。
> 光线追踪原理跳过。
> **和已有认知的差异**：2D 采样（ComfyUI 的 steps）控制生成质量；
> 这里的采样（Cycles Samples）控制渲染噪点——同名词不同含义（见 [NOTATION](../../NOTATION.md) 易混词）。

### 12.4 输出设置与出图

**概念定义**：设好分辨率、格式、保存路径，渲染并保存图片。
常见坑：忘了设路径/分辨率、渲染后没保存、透明背景设置。

**直觉类比**：像**按快门后记得存照片**——
设好照片尺寸（分辨率）、格式（png/jpg）、存哪（路径），
按下快门（F12），出片后"保存"（Save As）——少了最后一步白拍。

**界面 / 参数**：——
- **分辨率**：输出属性 → Resolution X/Y（如 1080×1080）；Resolution % 设为 100
- **格式**：Output → File Format → PNG（无损、可带透明）；JPEG（小）
- **透明背景**：渲染属性 → Film → Transparent（勾选后背景透明，方便抠图合成）
- **路径**：Output → Output Path 设保存目录
- **出图**：相机视角下按 `F12` 渲染 → 渲染窗口 `Image > Save As` 保存
- 快速预览也可在 3D 视图直接看 `Material Preview`（非最终渲染）

**常见误区**：
- ❌「渲染完以为自动保存了」—— 要 `Image > Save As` 手动保存。
- ❌「背景不透明没法合成」—— 勾 Film > Transparent 出透明底 PNG。

> **够用边界**：会「设分辨率 + PNG + F12 渲染 + Save As」这条出图流程即可。
> **和已有认知的差异**：2D 生成图直接存到 output 目录；
> Blender 渲染后要自己在渲染窗口 Save As——多一步手动保存。

## 小结

- 渲染四要素：相机（从哪拍）+ 灯光/世界（照明）+ 引擎（怎么算）+ 输出（尺寸/保存）。
- 最小流程：加相机 → 加面光 → 选 Eevee → 设输出 → F12 → Save As。
- 相机用 Shift+A 加、小键盘0 看视角；灯光用面光最省事；世界强度补环境光。
- Eevee 快、够用；Cycles 慢、真实——展示图 Eevee 常足够。渲染后记得手动保存。
