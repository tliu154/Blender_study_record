### 6.1 界面长什么样

**概念定义**：Blender 默认界面由几个「区域（Area）」组成，做后处理重点认三个——
**3D 视图**（中央大窗口，看/操作模型）、**大纲视图**（右上角，列出场景里的物体）、
**属性面板**（右下角，调物体/渲染等属性）。其余区域（时间轴、着色器编辑器等）用到再说。

**直觉类比**：像**驾驶舱**——
中间大挡风玻璃（3D 视图）看路况，右侧仪表盘（大纲 + 属性）看信息和调参数。
你大部分时间盯着挡风玻璃操作，偶尔看仪表盘调设置。

**界面 / 参数**：三个核心区域——
- **3D 视图（3D Viewport）**：中央最大区域，模型在这里显示和操作
- **大纲视图（Outliner）**：右上角，树状列出场景里的物体；点名字可选中/隐藏（眼睛图标）
- **属性面板（Properties）**：右下角，一列图标标签（渲染/输出/场景/世界/物体/修改器/材质等），当前选中物体的属性在这调
- 底部是**时间轴**（做动画才用，本篇可忽略）

**常见误区**：
- ❌「界面太复杂，不知从哪下手」—— 只盯 3D 视图 + 大纲 + 属性三块即可，其它先当不存在。
- ❌「默认立方体是模板的一部分」—— 它是个普通物体，导入模型前删掉它（见 [ch07](ch07_import.md)）。

> **够用边界**：能在界面里指出 3D 视图、大纲、属性面板各在哪就够。
> 其它区域遇到再认。
> **和已有认知的差异**：ComfyUI 是**节点画布**（在框之间连线）；
> Blender 是**3D 工作区**（在立体空间里操作物体）——两种完全不同的交互范式，别用节点思维套。

### 6.2 视图导航三件套

**概念定义**：在 3D 视图里移动"视角"靠三件套：旋转（Orbit）、平移（Pan）、缩放（Zoom）。
这是 Blender 最高频的操作，必须练到不用想。

**直觉类比**：像**围着一件展台上的雕塑看**——
旋转 = 绕着它走（换角度看），平移 = 你自己侧着挪步（视角整体移动），
缩放 = 走近/走远（看细节或看全貌）。鼠标就是你的脚。

**界面 / 参数**：三件套操作（鼠标中键是核心）——
| 操作 | 鼠标 | 效果 |
|---|---|---|
| **旋转 Orbit** | 按住**中键**拖动 | 绕物体转视角 |
| **平移 Pan** | `Shift` + 中键拖动 | 视角整体平移 |
| **缩放 Zoom** | **滚轮** | 拉近/拉远 |
| **框选全部** | 按 `Home` 键 | 一键把场景所有内容框进视野（找不到模型时救命）|
| **聚焦选中** | 小键盘 `.` 或 `View > Frame Selected` | 把选中的物体怼到眼前 |

- 忘记操作时，`View`（视图）菜单里有对应项

**常见误区**：
- ❌「用左键拖来转视角」—— 左键是**选择**，不是旋转；旋转用中键。
- ❌「导入模型后屏幕上什么都没有就慌」—— 按 `Home` 框选全部，多半是模型在视野外/太小（见 [ch07](ch07_import.md)）。

> **够用边界**：把「中键转、Shift+中键平移、滚轮缩放、Home 找全部」练熟，够用 90% 场景。
> **和已有认知的差异**：ComfyUI 画布是 2D 的（滚轮缩放、空格/中键拖画布）；
> Blender 是 3D 视角，中键**旋转**是最不同的新动作，需要肌肉记忆。

### 6.3 物体模式与编辑模式

**概念定义**：Blender 有两种最常用的工作模式——
**物体模式（Object Mode）**：把模型当整体操作（移动、旋转、缩放、选中物体）；
**编辑模式（Edit Mode）**：进入模型内部，操作顶点/边/面（修网格、减面、改法线）。
按 `Tab` 在两者间切换。后处理两种都要用：整体调整在物体模式，修网格在编辑模式。

**直觉类比**：像**看一栋楼**——
物体模式 = 站在楼外，移动整栋楼、转动它；
编辑模式 = 进到楼里，改某面墙、挪某根柱子（顶点/边/面）。
`Tab` 就是"进出楼门"的开关。

**界面 / 参数**：模式与快捷键——
- `Tab`：物体模式 ⇄ 编辑模式切换
- **物体模式**操作：`G` 移动（Grab）、`R` 旋转（Rotate）、`S` 缩放（Scale）——按后跟鼠标移动，回车确认
- **编辑模式**：顶部或快捷键切换元素层级——`1` 顶点 / `2` 边 / `3` 面；`A` 全选；`Alt+A` 取消全选
- 模式显示在 3D 视图左上角下拉菜单

**常见误区**：
- ❌「想改网格形状却在物体模式里拖」—— 物体模式只能整体移动/缩放，改形状要进编辑模式。
- ❌「按 Tab 没反应」—— 要先选中物体（大纲里点名字或视图里左键点），没选中无法进编辑模式。
- ❌「G/R/S 后物体跟着鼠标乱跑」—— 正常，移动鼠标到合适位置后**左键或回车确认**，`Esc` 取消。

> **够用边界**：会 `Tab` 切模式、`G/R/S` 操作整体、编辑模式里 `1/2/3` 切顶点/边/面、`A` 全选——这套够应付后处理。
> **和已有认知的差异**：ComfyUI 没有"模式"概念（一直是在画布上连线）；
> Blender 的**模式切换**是核心工作方式，做不同事要先切到对的模式。

### 6.4 选择、坐标与单位

**概念定义**：几个基础操作贯穿所有后处理：选中物体/元素、理解 3D 坐标系、了解单位尺度。
选不中、尺度乱是新手最常卡的地方。

**直觉类比**：像**动手前的准备**——
先选对要操作的对象（别改错东西），知道上下左右前后（坐标），
确认量尺标准（单位）——不然"移动 2 格"到底是 2 毫米还是 2 米？

**界面 / 参数**：——
- **选择**：左键点选；`A` 全选；`Alt+A` 取消；大纲视图里点名字也能选
- **坐标系**：底部/侧边有 XYZ 轴；Blender 默认 **Z 轴朝上**（很多游戏引擎是 Y 轴朝上，导出要注意，见 [ch04 4.4](../../01_comfyui_3d/docs/ch04_formats.md#c04-04)）
- **单位**：默认单位是米（场景属性里可改）；AI 模型导入后常"太小看不见"，用 `S` 放大或看 [ch07](ch07_import.md)
- **应用变换（Apply Transform）**：`Ctrl+A` → 选 Scale/Rotation，把物体的缩放/旋转"固化"进网格（导出前常做，避免下游尺度异常）

**常见误区**：
- ❌「Scale 缩放了模型但导出还是原大小」—— 没 Apply Transform，缩放只是物体属性没进网格数据（导出可能不认）。
- ❌「点不中模型」—— 可能被别的物体挡住，或在大纲里选中/隐藏处理。

> **够用边界**：会选中、`A` 全选、知道 Z-up、导出前 `Ctrl+A` Apply Scale 即可。
> 坐标系数学不用深究。
> **和已有认知的差异**：2D 里的"坐标"是屏幕上的 (x,y)；
> Blender 是 3D 的 (x,y,z) 且有 Z-up 约定——这是和很多引擎/2D 认知不同的点。

## 小结

- 做后处理只需认三个区域：3D 视图（看模型）、大纲（选物体）、属性面板（调参数）。
- 导航三件套：中键旋转、`Shift`+中键平移、滚轮缩放，`Home` 找全部——必练。
- `Tab` 切物体模式（整体 G/R/S）/ 编辑模式（`1/2/3` 顶点边面、`A` 全选）——修网格的核心。
- 选中、`A` 全选、Z-up 坐标、导出前 `Ctrl+A` Apply Scale——基础操作够用。
