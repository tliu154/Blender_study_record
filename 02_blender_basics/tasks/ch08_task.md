# 实操 08：修复一个 AI 模型的网格

> 对应章节：[第 8 章 网格清理与修复](../docs/ch08_mesh_cleanup.md) ｜ 预计耗时：50 分钟
> 状态：`[已完成]`

## 目标

对 ch07 体检出的问题模型，动手修法线、合并顶点、减面、平滑，让模型达到"能用"状态。
**如果模型本身没问题，可故意制造问题再修，练习工具使用。**

## 前提

- [ ] 已在 Blender 导入一个模型并完成体检（[ch07_task](ch07_task.md)）
- [ ] 会进编辑模式、全选、切顶点/边/面（[ch06](../docs/ch06_ui_navigation.md#c06-03)）

## 步骤

1. **记录基线**：修复前面数 ____、法线（Face Orientation 红/蓝）____、外观 ____。

2. **修法线**：编辑模式（`Tab`）→ `A` 全选 → `Shift+N` → 开 `Face Orientation` 检查是否大部分变蓝。
   - 修复后红色面：____（明显减少？）

3. **合并顶点**：`A` 全选 → `M` → Merge by Distance → 看面数/顶点数是否变化。
   - 顶点数变化：____ → ____

4. **减面**：回物体模式 → Add Modifier → Decimate → Ratio 设 0.5 → 观察外形与面数。
   逐步调低到外形"刚好不崩"，记录合适的值。
   - Ratio 最终 ____，面数 ____ → ____

5. *(若有破面)* **补洞/删面**：编辑模式选破面区域，小洞用 `F` 补、废面用 `X` 删。

6. **平滑**：物体模式右键 → Shade Smooth；若有硬边被糊掉，加 Weighted Normal 修改器。
   - 平滑后观感：____

7. **对比前后**：修复前后各截一张图/记一段描述，确认"能用"了。

## 验收标准

- [ ] 法线修复后 Face Orientation 大部分变蓝（不再发黑）
- [ ] 至少做了合并顶点与减面各一次，记录数据变化
- [ ] 减面后外形仍可接受
- [ ] 说清每个操作解决什么问题

## 改一改会怎样（小实验）

| 改动 | 预期现象 | 为什么 |
|---|---|---|
| 法线反的模型不修直接渲染 | 发黑/内外颠倒 | 法线决定受光，见 ch08 8.2 |
| Decimate Ratio 设到 0.05 | 外形严重崩坏 | 减面过度破坏造型，见 ch08 8.3 |
| 硬边模型全 Shade Smooth | 棱角糊掉 | 要加权法线保留硬边，见 ch08 8.4 |
| Merge by Distance 阈值调太大 | 误合并无关顶点、变形 | 合并距离要合适，见 ch08 8.3 |

## 常见问题

- Shift+N 后仍有红色 → 可能有破面/非封闭，先补面，见 [ch08 8.3](../docs/ch08_mesh_cleanup.md#c08-03)
- 减面后变形 → Ratio 调太低，往回调，见 8.3
- 平滑后棱角没了 → 用 Weighted Normal，见 8.4
- 其它 → [附录 C 故障排查](../../90_appendix/docs/appC_troubleshooting.md)
