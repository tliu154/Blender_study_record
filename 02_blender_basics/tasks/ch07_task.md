# 实操 07：导入一个 AI 模型并做体检

> 对应章节：[第 7 章 导入与检查模型](../docs/ch07_import.md) ｜ 预计耗时：40 分钟
> 状态：`[已完成]`

## 目标

把一个 AI 生成的 glb（ch02/ch04 的产物）导入 Blender，找到它，做一遍"体检"，
记录需要修复的问题，为 ch08 做准备。

## 前提

- [ ] 会导航三件套与模式切换（[ch06_task](ch06_task.md)）
- [ ] 有一个 glb 模型文件（ch02/ch03 生成 + ch04 导出）
- [ ] 若没有，可下载任意 glb 示例模型（如 Khronos glTF Sample Models）

## 步骤

1. **清空默认场景**：打开 Blender → 大纲视图选中 Cube → `X` 删除。

2. **导入**：`File > Import > glTF 2.0` → 选你的 glb → Import。按 `Home` 找模型。
   - 导入成功吗？____ ｜ 一眼看到吗？____

3. **体检六项**，逐项记录：
   - 在大纲里名字在吗？____
   - 面数多少？（属性面板统计 / 编辑模式全选看计数）____
   - 开 `Face Orientation` 叠加层：红色（反面）多吗？____
   - 切 `Material Preview`：有贴图/颜色吗？____
   - 朝向正吗？____ ｜ 大小合适吗？____

4. **摆正放稳**（物体模式）：若朝向歪/大小怪，用 `G/R/S` 调整，然后 `Ctrl+A` → Scale 应用变换。

5. **（演练看不见）**：故意把模型用 `G` 挪到很远，再用 `Home` 找回；
   或在大纲里点名字 + 小键盘 `.` 聚焦。体会"看不见≠坏了"。

## 验收标准

- [ ] 模型成功导入并找到
- [ ] 体检六项都填了记录
- [ ] 需要修的问题列了出来
- [ ] 演练过"挪丢再找回"

## 改一改会怎样（小实验）

| 改动 | 预期现象 | 为什么 |
|---|---|---|
| 不删默认立方体直接导入 | 场景里多一个立方体 | 默认物体不会自动消失，见 ch07 7.1 |
| 导入后用 Solid 着色说"没贴图" | 其实只是显示模式 | 切 Material Preview，见 ch07 7.2 |
| 模型看不见就反复重导 | 越导越多还是看不见 | 先按 Home/查可见性，见 ch07 7.4 |

## 常见问题

- 看不见 → Home → 看大纲 → 放大 → 查可见性，见 [ch07 7.4](../docs/ch07_import.md#c07-04)
- 导入 obj 是白模 → 贴图文件没一起放，见 [ch04 4.3](../../01_comfyui_3d/docs/ch04_formats.md#c04-03)
- Face Orientation 找不到 → 视图右上角叠加层（两个重叠圆球图标）下拉里勾选
- 其它 → [附录 C 故障排查](../../90_appendix/docs/appC_troubleshooting.md)
