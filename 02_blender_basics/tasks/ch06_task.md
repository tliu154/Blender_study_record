# 实操 06：练熟导航与模式切换

> 对应章节：[第 6 章 Blender 界面与视图操作](../docs/ch06_ui_navigation.md) ｜ 预计耗时：30 分钟
> 状态：`[已完成]`

## 目标

把 Blender 的导航三件套和模式切换练成肌肉记忆。这章不产出模型，纯练手——
后面所有操作都建立在这些动作上。

## 前提

- [ ] Blender 已安装并能打开（[ch01_task](../../01_comfyui_3d/tasks/ch01_task.md)）
- [ ] 默认场景里有个立方体（新开的 Blender 就有）

## 步骤

1. **认区域**：在界面上指出 3D 视图、大纲视图、属性面板各在哪，
   在大纲里点一下 "Cube" 看立方体是否被选中（变橙色轮廓）。

2. **导航三件套**（对着默认立方体练）：
   - 中键拖动：绕立方体旋转，从各个角度看
   - `Shift`+中键拖动：视角平移
   - 滚轮：拉近/拉远
   - 故意把视角转丢（立方体跑出屏幕）→ 按 `Home` 一键找回

3. **物体模式操作**：选中立方体，依次试：
   - `G` 移动（移动鼠标后回车确认）
   - `R` 旋转
   - `S` 缩放
   - 每次按 `Esc` 取消，回到原状

4. **切编辑模式**：选中立方体按 `Tab` → 进入编辑模式。
   依次按 `1`（顶点）/`2`（边）/`3`（面）看高亮的元素类型变化。
   按 `A` 全选，再 `Alt+A` 取消。按 `Tab` 回物体模式。

5. **找快捷键**：忘记了就点顶部 `View` 菜单，看里面列的对应操作。

## 验收标准

- [ ] 中键旋转、`Shift`+中键平移、滚轮缩放都练过，转丢能按 Home 找回
- [ ] 物体模式下 `G/R/S` 各操作一次并确认/取消
- [ ] 能用 Tab 切模式，编辑模式下 1/2/3 切换顶点/边/面

## 改一改会怎样（小实验）

| 改动 | 预期现象 | 为什么 |
|---|---|---|
| 用左键拖动想转视角 | 变成框选/没反应 | 左键是选择，旋转用中键，见 ch06 6.2 |
| 没选中物体就按 Tab | 进不去编辑模式 | 要先选中物体，见 ch06 6.3 |
| G 之后不确认就切别的操作 | 物体处于"待确认"状态 | G/R/S 后要回车/左键确认或 Esc 取消 |

## 可复现记录

| 项 | 值 |
|---|---|
| Blender 版本 | |
| 导航三件套是否练熟 | 是/否 |
| 模式切换是否顺畅 | 是/否 |

## 常见问题

- 找不到中键（笔记本触控板）→ 可在 `Edit > Preferences > Input` 开"模拟中键"，或用小键盘/快捷键替代
- 界面太小看不清 → 高分屏可在偏好设置调 UI 缩放
- 操作错了想重来 → `Esc` 取消当前操作；`Ctrl+Z` 撤销
