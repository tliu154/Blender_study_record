# 实操 12：给模型渲染一张展示图

> 对应章节：[第 12 章 渲染出图](../docs/ch12_render.md) ｜ 预计耗时：40 分钟
> 状态：`[已完成]`

## 目标

给处理好的模型架相机、打灯，用 Eevee 渲染一张展示图并保存。这是从第 1 篇生成到最终展示的收尾。

## 前提

- [ ] 模型已导入并后处理、有材质（ch07~ch10）
- [ ] 认识相机/灯光的添加（Shift+A）

## 步骤

1. **加相机**：`Shift+A` → Camera；摆到能拍到模型全貌的位置角度。
   小键盘 `0` 切到相机视角，用 `G/R/S` 调整构图（模型在画面中央、大小合适）。

2. **加灯**：`Shift+A` → Light → Area（面光），放模型前上方；`S` 调大灯板，
   属性面板调 Energy（强度）。观察模型是否亮起来。
   - （可选）加第二盏补光减弱阴影

3. **补环境光**：属性面板世界图标 → 调 Background 强度，避免死黑背景。

4. **选引擎**：渲染属性 → Render Engine → `Eevee`。

5. **设输出**：输出属性 → Resolution 设 `1080×1080`、Resolution% = 100、
   File Format = PNG、（可选）Film > Transparent 勾透明背景、设保存路径。

6. **出图**：相机视角下按 `F12` 渲染 → 看渲染窗口 → `Image > Save As` 保存。
   - 保存路径/文件名：____

7. **（对比）试 Cycles**：换 Cycles 渲染同一张，对比质量与耗时。
   - Eevee 耗时 ____ ｜ Cycles 耗时 ____ ｜ 观感差异 ____

## 验收标准

- [ ] 成功用 Eevee 渲染并保存了一张展示图
- [ ] 模型构图合理、照明可辨（不死黑不过曝）
- [ ] 记录了 Eevee vs Cycles 的质量/耗时差异
- [ ] 说清渲染四要素的作用

## 改一改会怎样（小实验）

| 改动 | 预期现象 | 为什么 |
|---|---|---|
| 不加灯直接渲染 | 全黑 | 没光源，见 ch12 12.2 |
| 大幅加大灯光 Energy | 过曝、丢细节 | 光太强，见 ch12 12.2 |
| Eevee 换 Cycles | 更真实但慢很多 | 光追 vs 实时，见 ch12 12.3 |
| 渲染完不 Save As | 图没保存 | 要手动保存，见 ch12 12.4 |

## 常见问题

- 渲染全黑 → 加灯/调世界强度/查相机是否被挡，见 [ch12 12.2](../docs/ch12_render.md#c12-02)
- 渲染报错没相机 → Shift+A 加 Camera，见 12.1
- 有噪点（Cycles）→ 加采样或开降噪，见 12.3
- 图没保存 → 渲染窗口 Image > Save As，见 12.4
- 其它 → [附录 C 故障排查](../../90_appendix/docs/appC_troubleshooting.md)
