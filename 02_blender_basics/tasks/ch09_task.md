# 实操 09：判断 UV 状况并自动展开

> 对应章节：[第 9 章 UV 展开入门](../docs/ch09_uv.md) ｜ 预计耗时：35 分钟
> 状态：`[已完成]`

## 目标

学会看一个模型的 UV 状况，按判断决定要不要重展；对需要重展的，用 Smart UV Project 自动展开。

## 前提

- [ ] 有一个模型在 Blender 里（ch07/ch08 的产物）
- [ ] 会进编辑模式、全选（[ch06](../docs/ch06_ui_navigation.md#c06-03)）

## 步骤

1. **打开 UV 编辑器**：切到 `UV Editing` 工作区，选中模型 → 进编辑模式 → `A` 全选，
   看 UV 编辑器里摊平的网格。
   - 现状：UV 岛分布 ____（合理/挤一团/重叠）｜ 模型有贴图吗？____

2. **判断要不要重展**（按 [ch09 9.4](../docs/ch09_uv.md#c09-04)）：
   - 有正常贴图 → 不用重展，记录"跳过"及理由
   - 白模要贴图 / 贴图错乱 → 继续下一步

3. **（需要时）自动展开**：编辑模式 `A` 全选 → `U` → Smart UV Project → 确认。
   看 UV 编辑器里重新摊平的结果。
   - 展开后 UV 岛：____（不重叠？分布如何？）

4. **联动观察**：在 UV 编辑器点一个 UV 岛，看 3D 视图里对应的是模型哪块——
   体会"UV 岛 ↔ 3D 表面"的对应。

5. **（可选）验证**：给模型临时贴一张棋盘格图片材质（ch10 会讲），
   看棋盘格是否均匀贴在模型上——不均匀说明 UV 有拉伸。

## 验收标准

- [ ] 能打开 UV 编辑器并描述 UV 岛状况
- [ ] 按判断表做出"重展 / 不重展"的决定并说明理由
- [ ] （需要时）完成一次 Smart UV Project 自动展开
- [ ] 理解了 UV 岛与 3D 表面的对应

## 改一改会怎样（小实验）

| 改动 | 预期现象 | 为什么 |
|---|---|---|
| 有正常贴图的模型也重展 UV | 原有贴图错乱 | 重展会丢原映射，见 ch09 9.4 |
| UV 岛重叠着贴图 | 不同部位贴到同一块图、错乱 | 重叠导致映射冲突，见 ch09 9.2 |
| 白模贴棋盘格看拉伸 | 拉伸处格子被拉长 | 检验 UV 质量，见 ch09 实操步骤5 |

## 常见问题

- UV 编辑器空白 → 没进编辑模式/没全选，先 `Tab` + `A`
- 找不到 U 菜单 → 右键 3D 视图也能找 UV Mapping 菜单
- 重展后贴图乱了 → 正常的映射重建，重新在 ch10 指定贴图，或回到有原 UV 的版本
- 其它 → [附录 C 故障排查](../../90_appendix/docs/appC_troubleshooting.md)
