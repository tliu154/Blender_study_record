# 实操 11：从 Blender 导出成品并验证

> 对应章节：[第 11 章 导出模型](../docs/ch11_export.md) ｜ 预计耗时：35 分钟
> 状态：`[已完成]`

## 目标

对处理好的模型走一遍导出前清单，导出 glb 成品，并在查看器里验证——
体会"导出成功 ≠ 正确显示"。

## 前提

- [ ] 有一个已后处理的模型（ch08 清理 + ch10 材质）
- [ ] 一个 glb 查看器（在线 glTF Viewer / Blender 重新导入 / 系统查看器）

## 步骤

1. **过检查清单**（按 [ch11 11.1](../docs/ch11_export.md#c11-01)）：
   - 只选中目标物体？____ ｜ 法线蓝为主？____ ｜ Apply 了 Scale/Rotation？____
   - 尺度合理？____ ｜ 贴图就位？____

2. **导出 glb**：`File > Export > glTF 2.0` → Format 选 `GLB` → 勾 Materials/Textures + Apply Modifiers →
   按目标设 +Y Up → 选好保存路径 → Export。
   - 记录文件名/大小：____

3. **验证**：在查看器打开导出的 glb，检查：
   - 外观/贴图正常吗？____ ｜ 朝向正吗？____ ｜ 尺度合理吗？____

4. **（可选）按用途再导一份**：选一个用途（打印→stl / 引擎→fbx），
   按 [ch11 11.3](../docs/ch11_export.md#c11-03) 导出，对比设置差异。

5. **制造一个坑**：故意不勾 Apply Modifiers 或只导 obj 不带贴图导出一次，
   在查看器看出现什么问题，对照 [ch11 11.4](../docs/ch11_export.md#c11-04)。

## 验收标准

- [ ] 导出前清单逐项过了一遍
- [ ] 成功导出 glb 并在查看器验证外观/朝向/尺度
- [ ] 说清 glb 导出关键设置的作用
- [ ] 至少观察到一种导出坑

## 改一改会怎样（小实验）

| 改动 | 预期现象 | 为什么 |
|---|---|---|
| 全选导出（含默认立方体） | 成品里多出杂物 | 只导目标物体，见 ch11 11.1 |
| glb 不勾贴图 | 白模 | 贴图没带上，见 ch11 11.4 |
| 不 Apply Scale 就导出 | 下游尺度可能异常 | 变换没固化，见 ch11 11.1 |
| 引擎朝向没设 +Y Up | 模型躺着/倒着 | 轴向差异，见 ch11 11.2 |

## 常见问题

- 导出是白模/粉红 → 贴图没带上，见 [ch11 11.4](../docs/ch11_export.md#c11-04)
- 到引擎朝向错 → 调 +Y Up，见 11.2
- 修改器没生效 → 勾 Apply Modifiers，见 11.4
- 其它 → [附录 C 故障排查](../../90_appendix/docs/appC_troubleshooting.md)
